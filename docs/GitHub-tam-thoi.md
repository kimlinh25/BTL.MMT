## Dùng GitHub Desktop

Nhận lời mời vào repo tạm bằng tài khoản thành viên đã dùng trong nhóm. Các tài khoản được mời gồm `d10keri`, `Minhlth`, `TT-ThanhTu`, `quan010605`. Người phụ trách gốc đã được ghi trong nội dung từng Issue, việc gán Assignees và mời review còn phụ thuộc việc nhận lời mời vào repo.

Mở đúng repo local, chọn Repository → Repository settings → Remote, đổi Primary remote repository thành `https://github.com/kimlinh25/BTL.MMT.git`, lưu và Fetch origin. Linh dùng tài khoản `kimlinh25` để xác thực khi làm trên repo tạm. Thành viên khác tiếp tục dùng tài khoản của chính mình.

Hai thư mục trên máy Linh đã được assistant cấu hình `origin` cho repo tạm và `original` cho repo gốc. Các thay đổi chưa commit vẫn cần được Linh xem lại và cất đúng nhánh trước khi Pull hay đổi nhánh.
